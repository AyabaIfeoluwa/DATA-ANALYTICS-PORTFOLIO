# Credit Risk & Loan Default Prediction

## Project Overview

This project focuses on analysing credit risk and predicting loan defaults using data analysis and machine learning techniques.

The objective is to identify borrower characteristics associated with loan default and develop predictive models that can support better credit risk assessment and lending decisions.

## Project Objectives

- Explore borrower characteristics and loan information.
- Identify factors associated with loan defaults.
- Clean and prepare the dataset for analysis.
- Apply feature engineering techniques.
- Develop machine learning classification models.
- Evaluate and compare model performance.
- Explore classification threshold adjustments to improve default detection.

## Tools and Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset

The dataset was obtained from Kaggle and contains borrower information, loan characteristics and loan repayment status.

The target variable is `loan_status`:
- 0 – Non-default
- 1 – Default

## Project Workflow

1. Data Loading and Initial Inspection
2. Data Quality Assessment
3. Exploratory Data Analysis (EDA)
4. Data Cleaning and Preparation
5. Feature Engineering
6. Model Development
7. Model Evaluation and Comparison
8. Model Improvement
9. Findings and Recommendations

## Machine Learning Models

Three classification models were developed and evaluated:

- Original Logistic Regression
- Tuned Logistic Regression
- Random Forest Classifier
